# 菜单优化建议

菜单整体分为

- 团队管理
 * 成员管理
 * 角色管理
 * API Key管理

- 渠道模型
 * 渠道管理
 * 模型管理

- 状态观察
  * 用量观察
  * 使用日志
  * 操作日志

- 系统设置

---

## 讨论结论（已定稿）

> 讨论时间：2026-11-02。各菜单项与现状能力映射如下，作为开发 plan 依据。

| 菜单项 | 现状 | 结论 |
|---|---|---|
| 团队管理-成员管理 | 已有 | 保留 |
| 团队管理-角色管理 | 无 | 新建 = 角色B `RoleTemplate` 管理页 |
| 团队管理-API Key 管理 | 已有 | 保留 |
| 渠道模型-渠道管理 | 已有 | 渠道 = Provider |
| 渠道模型-模型管理 | 已有 | 保留 |
| 状态观察-用量观察 | 已有 | 看板已有 |
| 状态观察-使用日志 | 部分有 | `UsageLog` 已存在，补分页明细接口 |
| 状态观察-操作日志 | 已有 | `AuditLog` 已有 |
| 系统设置 | 已有 | `SystemSetting` 已有 |

- 「渠道」统一指 `Provider`（上游渠道），避免与计费渠道、代理上游术语混用。
- 角色体系两层模型（角色A 管理范围 / 角色B 使用限制）详见 `docs/issue/团队管理功能的优化.md`。
