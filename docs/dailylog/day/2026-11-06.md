# 2026-11-06 工作日志

## 模型多渠道绑定与渠道优先级管理（MODEL_MULTI_CHANNEL）

实现模型目录模块的多渠道绑定功能：一个模型可同时绑定多个上游渠道，并为每个渠道设置数字优先级（越小越高）。模型列表新增渠道标签列，编辑表单支持多渠道选择与优先级输入。

**完成事项**

- 后端 Schema：`Model` 新增 `ProviderBinding` 子文档（`{ providerId, priority }`）+ `providerBindings` 数组，保留 `providerId` 向后兼容。
- 后端 DTO：`CreateModelDto` / `UpdateModelDto` 新增 `providerBindings` 可选字段（含 `ProviderBindingDto` 校验）。
- 后端 Service：`create/update/list` 支持 bindings；`list()` 调用 `resolveBindings` 批量查询 provider 名称；`providerBindings` 为空时从 `providerId` 回退。
- 后端级联适配：`ProvidersService.disable/enable` 不再级联到 Model；`remove` 调用 `ModelsService.removeProviderBinding` 移除绑定（无剩余绑定时禁用模型）。
- 前端类型：`ProviderBindingView` / `ProviderBindingInput`；`Model/ModelInput/ModelPatch` 新增 `providerBindings`。
- 前端页面：模型列表新增「渠道」列（tag 标签 + P{N} 优先级标注，主渠道高亮）；编辑表单新增「额外渠道绑定」区域（多选渠道 + 数字优先级 + 动态增删）。
- 文档落盘：plan/requirement + feature 追溯表。
- 验证：后端 test 215 passed / typecheck / lint；前端 typecheck / lint / build 全通过。
