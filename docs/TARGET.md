# 项目整体目标规划

## 本项目整体目标整理如下
为小型产研/办公团队提供一站式的AI接入服务，帮助快速接入市面常用模型并根据模型能力和办公场景需求给出一套模型选用方案来达到合理的Token成本控制和优化，其中包括接入国内用户访问受限的ClaudeCode/GPT/Gemini等先进国外模型，快速接入国内常用模型，对办公人员模型访问和Token进行合理限制，对Token使用做丰富可视化，持续优化团队Token使用

## 系统可分为3个主要部分
1. LLM中转站 实现模型流量中转分发，管理模型接入，账号流量池和路由，对Token成本的监控是团队级别的
2. 团队管理平台，被服务的每个团队可以通过此平台来添加成员/创建apikey/查看使用情况/查看logs等
3. 客户系统，面向我们自己，可以看到每个团队的基础情况及模型使用情况

## 参考项目
1. New Api
2. Portkey
3. LiteLLM

## 期望
对参考项目已经实现功能进行详细分析，梳理已有功能，通过充分的讨论来决定哪些功能是需要保留的合理功能，哪些功能是冗余无用的，先讨论处合理的功能架构，逐渐完善功能细节的需求，对UI进行合理优化
